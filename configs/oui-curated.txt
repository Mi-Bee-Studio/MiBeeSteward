# SPDX-License-Identifier: CC-BY-SA-4.0

# This is a HAND-MAINTAINED CC-BY-SA 4.0 table (authored by MiBee Studio from
# public knowledge of well-known vendor OUIs). It is EMBEDDED in the binary
# (internal/service/scannerv2/vendor/oui_curated.txt via //go:embed) so a fresh
# install gets vendor inference with no extra setup. For FULL coverage fetch
# the complete IEEE registries (MA-L / MA-M / MA-S) with scripts/fetch-oui.sh;
# that file is NOT bundled (IEEE data stays a separately-cited factual registry;
# see docs/fingerprint-spec.md §8 "Data vs code distinction").
#
# Format: <hex-prefix>\t<vendor>
#   - 6 hex  = MA-L (/24), the classic OUI block
#   - 7 hex  = MA-M (/28)
#   - 9 hex  = MA-S (/36, formerly IAB)
# Prefixes of different lengths may coexist (the loader does longest-prefix
# match). This curated set is mostly /24; longer prefixes are added where a
# small-vendor block is well-known.
#
